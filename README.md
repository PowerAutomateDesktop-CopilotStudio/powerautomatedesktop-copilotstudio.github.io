# powerautomatedesktop-copilotstudio.github.io

The home page of https://powerautomatedesktop-copilotstudio.github.io/ : one page that presents the two collections.

- `index.html`: a static page, no build. It reads `pad-samples/samples.json` and `copilot-studio-samples/samples.json`
  (published by each collection's site) to show the counts and the latest samples; without them the page stays as written.
- The collections live in their own repositories:
  [pad-samples](https://github.com/PowerAutomateDesktop-CopilotStudio/pad-samples) and
  [copilot-studio-samples](https://github.com/PowerAutomateDesktop-CopilotStudio/copilot-studio-samples).
